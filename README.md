# خطة التنشيف وبناء العضلات — Flask

## التشغيل على Windows

1. ثبّت Python 3.10 أو أحدث.
2. افتح CMD أو PowerShell داخل مجلد المشروع.
3. أنشئ بيئة افتراضية (اختياري لكنه مستحسن):

```powershell
py -m venv .venv
.venv\Scripts\activate
```

4. ثبّت المتطلبات:

```powershell
py -m pip install -r requirements.txt
```

5. شغّل التطبيق:

```powershell
py app.py
```

6. افتح العنوان الذي يظهر في الطرفية، غالبًا:
   http://127.0.0.1:5000

البيانات محفوظة محليًا في المتصفح باستخدام `localStorage`، مثل سجل الوزن والوجبات وأوزان التمارين وعلامات الإنجاز. ستظل البيانات على نفس المتصفح والجهاز ما لم تُمسح بيانات الموقع.
