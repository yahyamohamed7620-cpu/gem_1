# Kuwait Market — منصة دروبشيبينج

منصة تجارة إلكترونية (دروبشيبينج) على طريقة ecomerg: المسوّق يسجّل، يتصفّح المنتجات،
يحدّد سعر البيع، يعمل طلبات لعملائه، ويكسب عمولة على كل طلب يتسلّم. والأدمن يدير
المنتجات والطلبات وطلبات السحب والمسوّقين.

مبنية بـ **Python القياسي فقط** (بدون أي مكتبات خارجية) + **SQLite** + واجهة HTML/CSS/JS.

## التشغيل

```bash
cd kuwait-market
python3 seed.py     # مرة واحدة: يجهّز قاعدة البيانات وبيانات تجريبية
python3 app.py      # يشغّل السيرفر
```

ثم افتح المتصفح على: **http://localhost:8000**

## حسابات جاهزة للتجربة

| الدور   | الإيميل                  | كلمة المرور |
|---------|--------------------------|-------------|
| أدمن    | `admin@kuwaitmarket.local`    | `admin123`  |
| مسوّق   | `marketer@kuwaitmarket.local` | `demo123`   |

أو سجّل حساب مسوّق جديد من زر «سجّل الآن».

## المميزات

**للمسوّق:**
- تسجيل / دخول آمن (كلمات المرور مشفّرة PBKDF2)
- تصفّح المنتجات + سلة + تحديد سعر البيع ضمن الحد المسموح
- عمل طلبات لعملاء مع بياناتهم
- لوحة تحكم: إحصائيات، طلباتي، المحفظة
- طلب سحب الأرباح من الرصيد المتاح

**للأدمن:**
- إدارة كل الطلبات وتغيير حالتها (العمولة تُصرف تلقائياً عند «تم التسليم»)
- مراجعة طلبات السحب (دفع / رفض — الرفض يرجّع الرصيد)
- إدارة المسوّقين + حظر / فك حظر
- إضافة منتجات جديدة

## بنية المشروع

```
kuwait-market/
├── app.py            # السيرفر + الـ API + التوجيه
├── db.py             # قاعدة البيانات والسكيمة والتشفير
├── seed.py           # البيانات الأولية
├── ecomerg.db        # قاعدة البيانات (تتولّد تلقائياً)
└── static/
    ├── index.html    # الصفحة الرئيسية (SPA)
    ├── style.css     # التصميم
    └── app.js        # منطق الواجهة بالكامل
```

## ملاحظات للتطوير لاحقاً

- **صور حقيقية للمنتجات** بدل الأيقونات (رفع صور).
- **بوابة دفع** حقيقية (KNET / MyFatoorah) لتحصيل قيمة الطلب.
- نقل الباك-إند لإطار عمل (Flask/FastAPI) + قاعدة بيانات PostgreSQL عند التوسّع.
- نشر على سيرفر (VPS) بـ Nginx + Gunicorn أو ما شابه.
- تطبيق موبايل (الموقع جاهز كـ responsive، ممكن تغليفه PWA).

> نسخة تعليمية/أولية جاهزة للتطوير. البيانات محلية على جهازك فقط.
